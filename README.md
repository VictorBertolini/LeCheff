# Le Cheff

O [Chef Signorelli](https://www.instagram.com/chef_signorelli/) oferece serviços de alta gastronomia realizados na residência dos clientes ou em eventos. Atualmente, o processo de contratação ocorre principalmente pelo WhatsApp, onde o cliente consulta a disponibilidade, conhece o menu, recebe um orçamento e confirma o serviço.

O sistema proposto busca centralizar e organizar esse processo, permitindo que o cliente consulte os pratos disponíveis, informe a quantidade de pessoas, endereço e data desejada, realizando uma solicitação que posteriormente será analisada pelo chef.

Além disso, o sistema auxiliará o chef na organização da agenda e no planejamento dos ingredientes, calculando as quantidades necessárias de acordo com o número de convidados e os pratos escolhidos, reduzindo problemas como conflitos de datas, erros no menu e falta de alimentos.
